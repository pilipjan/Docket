Off by default — turning this on sends new Improvement Log entries straight to a Supabase project you set up and control, not to Anthropic or any third party. You'll need a table (default name below) with columns ts, type, detail, source (all text), and a Row Level Security insert policy that allows your anon key to insert. The anon key is stored only in this browser's local storage, same as everything else here.
